組合題：求出差分的根，就找到真正極值了嗎？
固定 P(x) = x³ − 3x + 1。解析極小位置為 x = 1；一階中央差分在精確算術下為 D1 = 3x² − 3 + h²，正根 xh = √(1 − h²/3)。

公式與誤差從哪裡來
中央一階差分為 [f(x+h)−f(x−h)]/(2h)，截斷主項為 f‴(x)h²/6；中央二階差分為 [f(x+h)−2f(x)+f(x−h)]/h²，截斷主項為 f⁽⁴⁾(x)h²/12。函數足夠平滑時，兩者通常都有 O(h²) 截斷誤差。
E4 是三次式：D1 = 3x²−3+h²，D2 = 6x 在精確算術下成立。因此 E4 二階公式沒有截斷誤差；畫面若出現誤差，來自浮點計算。h 太小會讓相近數相減後的有效位數減少，再被 1/h 或 1/h² 放大。
VBA 一階：(P(x + h) - P(x - h)) / (2 * h)
VBA 二階：(P(x + h) - 2 * P(x) + P(x - h)) / (h * h)
求根 tol 與微分 h 使用不同變數。
