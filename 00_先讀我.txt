數值方法｜10/07 小考準備教材
製作日期：2026-10-03

這個資料夾包含四類核心教材與兩版互動 HTML，可整個分享給同學。
教材依課程資料及目前討論的範圍編寫；數值微分組合題列為可能考點，並非老師正式公布的命題保證。

本次範圍
二分法、假位法、Newton 求根、割線法；Taylor 展開與截斷／捨入誤差；
Lagrange 插值、Newton 差商插值；一階／二階數值微分，以及插值、求根、極值、反曲點的組合。
本套不包含數值積分及後續章節。

教材與建議用途

01_考前講義.pdf（16 頁）
  白話觀念、公式、手算範例、Excel/VBA 讀碼、常見錯誤與短練習。
  不熟觀念時，先讀相關章節，再動手操作。

02_Excel_VBA實作
  01_完整示範.xlsm：E1 求根、E2 Taylor 與誤差、E3 歷屆插值改編、E4 自編組合題。
  02_骨架練習.xlsm：自行完成公式與 VBA 的 TODO。
  閱讀與操作說明.txt：開啟、執行巨集、函數參數、中文讀碼導覽。
  NM_Core.bas / NM_Practice.bas：可閱讀與匯入的 VBA 原碼。

03_實作模擬考
  01_兩回模擬考_題本.pdf（8 頁）：A 卷偏歷屆改編，B 卷偏新題與方法遷移。
  A_B_模擬考起始檔.xlsm：對應 A1～A4、B1～B4，保留題目輸入與作答區。
  02_分層提示.pdf（2 頁）：卡住時先看第一層，仍不會再往下看。
  03_詳解與評分規準.pdf（8 頁）：完成後核對步驟、數值、停止條件與配分。

  起始檔說明.txt / NM_Mock.bas：操作說明與空白作答模組。

04_雙面速查表.pdf（2 頁）
  用途、公式、停止條件、程式要點與易錯處。可 A4 雙面列印，選長邊翻頁。
  適合平時上機練習與考前複習；是否能帶進正式考場，依老師規定。

05_互動式數值方法實驗室.html
  用 Edge、Chrome 或其他現代瀏覽器直接開啟，不需連線、安裝或啟動伺服器。
  四個單元：求根逐步播放、Taylor 誤差、可拖動資料點的內插曲線、微分步長。
  每個單元附兩步實驗、預測問答與對應模考題號；可下載本次求根迭代 CSV。
  HTML 單檔即可運作。若要使用其中的講義、速查表、BAS 及模考連結，請保留整個資料夾結構。
  圖表運算採雙精度，末位可能與 Excel 略有差異；步長極小而無法區分 x 與 x±h 時會提示。

06_實作應考訓練室_第二版.html
  新增檔案，第一版原檔保留。可用瀏覽器離線開啟，互動實驗也已內嵌，不依賴第一版外部檔案。
  包含 E3 六關組合題、兩回各六題的限時短測、六題 VBA 除錯，以及紀錄與錯題整理。
  短測預設 25 分鐘，可自訂；與前述 PDF 模擬考是不同題組、不同訓練時間設定。
  紀錄存在目前瀏覽器。換電腦或備份時，從「紀錄與錯題」匯出 JSON，再於另一台匯入。
  分享 HTML 本身不包含你的作答紀錄；講義等外部教材連結仍需要保留整個資料夾結構。

建議使用順序
1. 講義先看求根、插值與數值微分的核心觀念。
   遇到不易想像的地方，開 HTML 改初值、degree、資料點或 h，先預測再觀察。
2. 開完整示範，改黃色輸入格，先預測結果，再重算並觀察誤差與迭代紀錄。
3. 做骨架練習，嘗試不看答案完成；用節點回代、殘差和解析結果驗算。
   第二版 HTML 可穿插進行組合題闖關、VBA 除錯，再用限時短測檢查理解。
4. 限時做 A 卷，批改後補弱點；再做 B 卷，檢查能否處理換函數與新組合。
5. 最後用速查表口頭解釋每個公式、輸入條件和停止原因。

Excel 使用要點
請使用支援 VBA 的桌面版 Microsoft Excel；先閱讀 02 資料夾內的操作說明。
XLSM 已內嵌巨集，無須再次匯入 BAS。BAS 是閱讀、備份與自行改寫用的原碼。
請先另存一份作答副本，保留乾淨教材方便重練。
骨架函數未完成時的 #N/A 是預期提示；完整示範應有可核對的數值結果。

重要觀念
Newton 求根和 Newton 差商插值是不同用途的方法。
h 是微分步長，tol 是求根停止門檻；把 tol 調小不會消除固定 h 的差分誤差。
完整示範對插值函數的 Newton 預設以差分估計導數；A2 詳解用解析導數，
兩者迭代細節可能不同，如何改成解析導數已寫在操作說明。
極值判斷需要分類駐點；區間全域極值還要比較端點。
